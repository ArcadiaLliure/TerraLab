# Fase 06 - Checklist de paritat visual

Executa cada comprovacio amb el pipeline per defecte i, si cal comparar-lo,
amb `TERRALAB_CELESTIAL_RENDERING_PIPELINE=legacy` abans d'iniciar TerraLab.

- Recorrer 24 hores: Sol, Lluna i planetes no salten durant canvis de temps.
- A l'horitzo: confirmar refraccio i aplanament vertical dels discs.
- Lluna nova, quart i plena: la fraccio il·luminada canvia de forma continua.
- Torroja 2026, UTC 17:35-19:20: parcialitat, totalitat, corona i recuperacio
  tenen contacte visual coherent amb l'escala fisica.
- Verificar nom, etiqueta, magnitud i click dels planetes visibles.
- Activar trails nocturns: trajectoria circumpolar, RA prop de 0/360, cache
  estable en repintats i absencia de punts d'estrelles duplicats.
- Fer pan, zoom, scope, resize, restart del renderer i canvis rapids de temps.

Resultat: pendent de confirmacio humana.
